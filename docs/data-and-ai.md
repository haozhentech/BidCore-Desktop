# 数据与模型服务说明

- 项目文件、公司档案和资料库保存在你电脑上的数据目录。目录如果放在网盘或同步软件里，也会受这些软件的同步设置影响。
- 写作、识图、配图和标书审查需要联网。使用时，完成任务所需的文字、图片或文件片段会经 BidCore 的服务器（位于中国香港）转发给模型服务商（目前为 DeepSeek 和硅基流动）处理，适用这些服务商的条款和隐私政策。
- BidCore 的服务器记录每次调用的密钥、时间、模型和用量，用于计费和余额查询，不保存你发送的内容。
- 费用按实际用量从 BidCore 密钥的积分里扣（1 积分 = 0.1 元用量）。密钥请妥善保管；发现泄露请尽快联系我们停用并换发。
- 要求标书资料不经过我们服务器的单位，可以选择私有化部署：部署到你自己的服务器或内网，接入你指定的模型服务。
- 反馈问题时，不要公开上传密钥、客户原件或未公开的投标材料；日志和截图请先检查敏感内容。

完整说明见官网的[隐私政策](https://bidcore.cn/privacy.html)。BidCore 由长沙芠硕科技有限公司开发和运营。

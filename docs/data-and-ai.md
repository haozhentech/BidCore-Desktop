# 数据与模型服务说明

项目文件、企业档案和本地资料库保存在用户选择的本机目录。目录若由网盘、企业备份或其他同步软件管理，也会受到这些软件的同步设置影响。

使用 AI 功能时，相关文本、图片或文件片段会发送到用户配置的模型服务。本地部署软件不等于模型推理完全离线。数据处理和保留方式取决于所连接服务及账户设置。

联网搜索、图像生成或在线文档编辑等可选功能可能连接额外服务；启用前请核对服务地址、凭据及对应条款。

公开版不提供开发者的付费模型 Key。使用者自行申请和管理 Key、余额及额度。模型调用费用与软件授权费用分别计算，软件的价格和授权以正式发行说明为准。

当前开发版使用 Windows 账户关联的系统保护能力加密保存凭据。分享配置码会省略凭据，接收者须填写自己的 Key。配置码用于分享连接设置，不是试用授权；搬迁到另一台电脑后可能需要重新输入密钥。

反馈问题时，不要公开上传 API Key、访问令牌、客户原件或未公开投标材料。日志和截图也应先检查敏感内容。

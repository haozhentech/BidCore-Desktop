# 常见问题

## 本地部署是否完全离线？

项目与资料在本机管理。云端 AI 需要联网，并把任务需要的内容发送到用户配置的服务；详见数据说明。

## 为什么需要自己的 API Key？

模型调用由自己的服务商账户计费，费用和额度可自行管理。软件授权与模型费用是两回事。

## 能否用于多家公司？

产品按公司档案绑定项目与资料。使用时应核对当前公司和资料归属，避免把参考样标中的旧项目事实用于新项目。

## 能否直接提交生成的文件？

需要人工复核。报价、真实证明材料、签章、采购文件要求与平台提交规则由使用者确认。

## 是否开源？

核心软件源码为私有。此仓库公开产品说明、文档、反馈和版本发行信息。

## 哪里下载？

在 [Releases](https://github.com/haozhentech/BidCore-Desktop/releases/tag/v0.10.0-canvas.299-beta) 下载安装版或便携版。当前版本未签名，下载无需登记。软件使用范围见公开测试版条款，AI 调用由自己的模型账户计费。

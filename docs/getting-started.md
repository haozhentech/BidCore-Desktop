# 使用指南

从 [Releases](https://github.com/haozhentech/BidCore-Desktop/releases/tag/v0.10.0-canvas.299-beta) 下载 Setup.exe 并运行安装，或下载 Portable.exe 直接启动。需要 Windows 10 / 11 x64。当前是未签名测试版，Windows 可能提示发布者未知；请核对来源和同版本 SHA256SUMS.txt。安装无需填写 API Key。

PowerShell 校验命令：`Get-FileHash -Algorithm SHA256 -LiteralPath '下载的EXE完整路径'`。将结果与发行页的校验文件对照。

## 第一次使用

想先了解界面，可以在首页打开“离线示例”，直接查看章节和编辑正文。示例不调用 AI，不需要 API Key；内容均为虚构，只能导出带标记的草稿，不能用于真实投标。

1. 打开软件，查看本地数据目录。将备份保存到另一个可靠位置。
2. 新建项目，选择已有企业或填写企业名称。具体企业事实可后补；正式交付时仍须完整。
3. 点击“模型设置”，选择服务商，填写自己的 API Key 和模型名称，测试连接并保存。默认推荐 DeepSeek V4.1 Flash，官方模型名为 `deepseek-flash`。测试连接和使用云端模型可能产生服务商费用。
4. 导入招标文件，检查提取结果，确认要求和目录后再继续编写。
5. 按提示补齐资质、业绩等资料，检查正文与来源并人工复核。
6. 导出 Word，检查版式、事实、附件、报价与签章要求。

默认工作台用于阅读文件、查看章节与编辑正文。点击“AI 编写与计划确认”可进入画布，确认大纲和写作计划、查看生成进度；点击“返回工作台”回到章节视图。

![项目工作台，虚构示例内容](../assets/workbench-preview.png)

官网提供[四步图解教程](https://bidcore.cn/download.html#quickstart)。Word 导出后可继续编辑；安装 LibreOffice 后，软件可用它刷新目录并转换 PDF。也可以在 Microsoft Word 中打开 DOCX，再另存为 PDF。不同排版引擎的分页可能不同，两种输出均须逐页核对。软件内置 PDF 备用引擎适合草稿预览。

固定表单、报价表和证明附件必须对照招标原件检查。自动识别或填充未覆盖的格式应使用原表补齐；生成草稿不能代替真实资质、报价和签章。

多包项目当前可导出汇总审阅稿。若招标要求各包独立装订，需按各包要求分别整理封面、正文、表单、报价与附件；汇总稿不能直接代替分包提交文件。

## 升级与备份

升级前备份项目及关联原文件。后续版本的最低系统要求、迁移行为和已知问题会随发行说明提供。

不要将整个数据目录公开上传。将数据搬到另一台电脑后，受操作系统保护的凭据可能需要重新填写。
